OS Answers (Ref: Silberschatz, Galvin, Gagne)

Q1. Services and functions of an OS

An OS is a program that manages the hardware and acts as an intermediary between user and hardware. It is a resource allocator and a control program.

Services (Sec 2.1)

Helpful to the user:

  1. User interface – CLI, GUI or batch. Eg: Bash, Windows Explorer.
  2. Program execution – loads program into memory, runs it, ends it normally or with error.
  3. I/O operations – users can't control devices directly (protection), so OS does I/O.
  4. File-system manipulation – create, delete, read, write, search files, set permissions.
  5. Communication – between processes, by shared memory or message passing.
  6. Error detection – in CPU, memory, I/O devices and user programs (eg illegal memory access).

For efficient working of system:

  1. Resource allocation – CPU, memory, files, devices given to many users/jobs.
  2. Accounting – tracks which user uses how much resource.
  3. Protection and security – controls access to resources; authentication of users.

Functions (Ch 1)

  • Process management – create/delete, suspend/resume, scheduling, synchronization, deadlock handling.
  • Memory management – track used memory, allocate/deallocate, paging, swapping, virtual memory.
  • Storage management – file system, disk scheduling, free space, caching.
  • I/O management – buffering, caching, spooling, device drivers.
  • Protection – dual mode (user/kernel), memory protection, timer.
